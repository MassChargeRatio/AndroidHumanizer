其他语言调用

启动本地服务后，任意语言通过 HTTP 调用：

touch-humanization-web --port 8765
curl -X POST http://127.0.0.1:8765/api/gesture \
  -H "Content-Type: application/json" \
  -d '{"start":[100,1800],"end":[900,400],"seed":42}'
高级参数（与 Python 版 kinetics 对齐） 

      
    

    

      起点  终点 
      · 轨迹由三次贝塞尔 + Fitts 步数 + smoothstep 速度轮廓 + 末段高斯微颤 + 过冲回拉生成
      · 同 seed 可复现（PRNG：mulberry32）
    

  


  

    

      
它是什么

      
把 Android 自动化里「像人一样操作」的三件事抽成独立库：

      
    
        
  • kinematics：贝塞尔轨迹 / Fitts 步数 / 末段微颤 / 过冲回拉 / 滑块分支
    • 
        
  • timing：对数正态时序（均值校正 mu=ln(mean)-σ²/2）/ 作息窗口 / 冷却限流
    • 
        
  • sensors：resting / walking / tapping / scrolling 序列 + 死寂检测
    • 
      

      
零运行时依赖；全部随机走实例级 random.Random；CI lint 禁止全局 random.*。

pip install touch-humanization

from touch_humanization import Humanizer

h = Humanizer(seed=42)
g = h.gesture((100, 1800), (900, 400))
for (x, y), dt in zip(g.points, g.intervals):
    ...  # 逐点注入 touch down/move/up
