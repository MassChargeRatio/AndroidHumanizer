它是什么 / What is it

      
把 Android 自动化里「像人一样操作」的三件事抽成独立库：
        / The three "operate like a human" concerns of Android automation, as a standalone library:

      
    
        
  • kinematics：贝塞尔轨迹 / Fitts 步数 / 末段微颤 / 过冲回拉 / 滑块分支
          — bezier trajectory / Fitts steps / tail tremor / overshoot / slider branch
    • 
        
  • timing：对数正态时序（均值校正 mu=ln(mean)-σ²/2）/ 作息窗口 / 冷却限流
          — lognormal timing (mean-corrected) / wake window / cooldown
    • 
        
  • sensors：resting / walking / tapping / scrolling 序列 + 死寂检测
          — sequences + deadness detection
    • 
      

      
零运行时依赖；全部随机走实例级 random.Random；CI lint 禁止全局 random.*。
        / Zero runtime deps; all randomness via instance-level random.Random; CI lint forbids global random.*.
