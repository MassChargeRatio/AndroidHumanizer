安装与下载Install & Download

Python 包Python package

PyPI 暂不可用（未发布），请从 GitHub Releases 下载 wheel 后安装：PyPI is not available yet (unpublished); install a wheel from GitHub Releases:

pip install touch_humanization-*.whl
打开最新 Release →Open latest Release →

安装后：After install: from touch_humanization import Humanizer

便携版Portable

免 pip 的 zip 包，解压后运行启动脚本（需系统 Python 3.9+）：pip-free zip; unzip and run the launcher (needs system Python 3.9+):

  • touch-humanization-portable-*.zip
  • Windows: run-web-ui.bat · Linux/macOS: ./run-web-ui.sh
下载便携版 →Download portable →

其他语言调用Call from other languages

启动本地服务后，任意语言通过 HTTP 调用：Start the local server, then call it over HTTP from any language:

touch-humanization-web --port 8765
curl -X POST http://127.0.0.1:8765/api/gesture \
  -H "Content-Type: application/json" \
  -d '{"start":[100,1800],"end":[900,400],"seed":42}'

Node.js / Go / Rust 同理，只需 HTTP POST JSON。完整 API 见 README。Same for Node.js / Go / Rust — just HTTP POST JSON. Full API list in the README.
