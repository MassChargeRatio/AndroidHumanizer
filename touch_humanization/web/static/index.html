touch-humanization

拟人化手势 · 时序 · 传感器 —— 交互式预览（零第三方依赖）

安装与下载 / Install & Download

Python 包（pip）

pip install touch-humanization

从 PyPI 安装；安装后可在任意 Python 项目里 from touch_humanization import Humanizer。

打开 PyPI 页面 →

安装包 / 便携版下载

wheel、sdist、便携版由 CI 构建后挂到 GitHub Releases。

打开最新 Release →
  • touch_humanization-*.whl — 任意平台，pip 可装
  • touch_humanization-*.tar.gz — sdist 源码包
  • touch-humanization-portable-*.zip — 免 pip 便携包，解压后运行启动脚本（需系统 Python 3.9+）

其他语言调用

启动本地服务后，任意语言通过 HTTP 调用：

touch-humanization-web --port 8765
curl -X POST http://127.0.0.1:8765/api/gesture \
  -H "Content-Type: application/json" \
  -d '{"start":[100,1800],"end":[900,400],"seed":42}'

Node.js / Go / Rust 同理，只需 HTTP POST JSON。完整 API 见 README。
